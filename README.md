# Odyssee Theme

Tema WordPress customizado e moderno desenvolvido para **Odyssee Experience**.

## Características
- Suporte a temas Claro (Light) e Escuro (Dark).
- Hero 3D interativo com esferas orbitais e cards de habilidades (WebGL / Three.js).
- Layout responsivo otimizado para dispositivos móveis e desktops.
- Painéis administrativos dedicados para personalização de conteúdo (FAQ e CV).
- Otimização de segurança com Content Security Policy (CSP) e cabeçalhos modernos.
